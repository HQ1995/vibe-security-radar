# Vibe Security Radar

[Georgia Tech SSLab](https://gts3.org/) catalog of public vulnerabilities whose root cause traces to AI-written code.

**https://vibesecradar.com/**

Each case is a disclosed GHSA or CVE where we can show the AI change, the vulnerable behavior, and the fix. There are 195 such findings in the 2025-05 – 2026-08 window. That is not a count of every AI bug — only the ones with a public advisory and a recoverable history.

A case looks wrong, or we missed one: [open an issue](https://github.com/HQ1995/vibe-security-radar/issues) or email hanqing@gatech.edu.
