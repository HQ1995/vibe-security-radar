Co-authored-by / assisted-by / AI author email = AI 写的，不再讨论主笔是谁。

## 3. Bot exclusion (dependency/CI bots are NOT AI authorship)
dependabot, renovate, greenkeeper, snyk, pyup, codeql (email substring).

## 4. Code-writing test
Stage-2 check: marker commit must touch code files (CODE_EXT list) and not
only docs/config (NON_CODE list); scan ladder: treeless marker scan ->
blob:none code check -> gitiles-log-JSON fallback for giant repos
(chromium). Per-case: git show/blame to tie the marker commit to the
vulnerable lines.

## 5. Verdict gates (per case)
identity / ai_hunk / topology / but_for / fix_reversal / release /
uniqueness. STRICT = all PASS. NARROW = gate gaps with evidence missing.
Settled rulings: co-author trailer counts as ai_hunk PASS; sync commits of
upstream code still need topology/identity evidence on the vulnerable lines.
