0.6.0: SCA enrichment — EOL-aware container image checks

0.6.0: SCA enrichment — EOL-aware container image checks

First post-PRD release. Adds CVE/EOL awareness to existing pipeline
findings without becoming a full SCA tool. ciguard remains a pipeline-
configuration scanner; this release adds dependency awareness for the
container images and language runtimes referenced inside the pipeline.

Headline use-case: pipelines silently accumulate `python:3.9`, `node:16`,
`alpine:3.16`, `debian:11` references that go EOL and stay in production
for years afterwards. ciguard now flags these.

New rules:
  - SCA-EOL-001 — End-of-Life Container Base Image (Critical/High)
  - SCA-EOL-002 — End-of-Life Language Runtime (Critical/High)
  - SCA-EOL-003 — Image Approaching End-of-Life ≤90d (Info)
  - SCA-PIN-001 — Image Pinned by Tag, Not by Digest (Low)

Data source: endoflife.date (free, vendor-neutral, ~250 products).
On-disk cache at ~/.ciguard/cache/ with 24h TTL — pipeline scans stay
fast and the cache survives across runs.

CLI:
  - `--offline` flag disables network lookups (air-gapped CI)
  - `AnalysisEngine(enable_sca=False)` opt-out for callers / tests

Cross-platform: SCA rules run for GitLab CI (job image:), GitHub Actions
(jobs.<id>.container + services), and Jenkins (Declarative agents at
top-level + per-stage + parallel children).

Validation:
  - 318 / 318 tests passing (was 288; +30 SCA tests in test_sca_rules.py)
  - Real-world smoke against python:3.9-slim, alpine:3.16, node:18-alpine
    correctly flags all three Critical with accurate EOL dates
  - All existing fixtures pass with enable_sca=False — zero regression

NOT in scope (deliberate):
  - General SCA on user's project deps (requirements.txt, package.json) —
    that's the Snyk / Dependabot / Nexus IQ space, we complement not compete
  - Custom vulnerability database — OSV.dev planned for v0.6.1 covers CVEs
  - License compliance — separate adjacent product

0.6.1: SCA CVE + graduated EOL tiers + EOS detection

SCA-EOL-003 severity from a single Info tier to High/Medium/Low based on
remaining runway, and introduces SCA-EOS-001 for end-of-active-support

Trivy/Grype lane and ciguard would compete, not complement. The EOL tier
graduation gives most of the same risk signal at the cycle level.

caches. Documented as BREAKING for SCA-EOL-003 severity in CHANGELOG.
