# w395 re-research

## Decision

**PARTIAL** with the disagreement memo. The memo is right to reject the primary `FALSE_POSITIVE`: the dependency-owned route is mounted by PDFMathTranslate, the CVE remains `PUBLISHED`, and the reviewed GHSA still names `pdf2zh` 1.9.9 with no patched version. It is wrong that the Gradio BIC remains unavailable: Gradio PR #2256 preserves all seven pre-squash commits, and the first member is the atomic writer of the redirect branch. Recommended primary verdict: **`NOT_AI`**. Recommended review verdict: **`CORRECTION_REQUIRED`** (the primary verdict and causal fields must change). [CVE record](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2025/50xxx/CVE-2025-50736.json) [GHSA](https://github.com/advisories/GHSA-pfrv-63w8-q7rq) [PR #2256](https://github.com/gradio-app/gradio/pull/2256)

## Vulnerability mechanism

CVE-2025-50736 describes an attacker-controlled external URL in the `file` parameter of `/gradio_api` producing an open redirect. The current CVE record is `PUBLISHED`, describes PDFMathTranslate v1.9.9, and classifies the issue as CWE-601; GitHub's reviewed advisory likewise lists `pdf2zh` exactly `1.9.9`, no patched version, and the `/gradio_api` file parameter. [CVE record](https://raw.githubusercontent.com/CVEProject/cvelistV5/main/cves/2025/50xxx/CVE-2025-50736.json) [GHSA](https://github.com/advisories/GHSA-pfrv-63w8-q7rq)

The mechanism replays directly from the relevant objects. PDFMathTranslate tag `v1.9.9` dereferences to `8ef72df455bd9cdae2666b8e63b8d298e5e5dd78`; its `pyproject.toml` declares unpinned `gradio`, and its `pdf2zh/gui.py` calls `demo.launch()`. Gradio tag `gradio@5.29.0` dereferences to `479fc28f804c674e3705763be199dacb0f5dca79`; `create_app()` mounts an `APIRouter` at `/gradio_api`, and `GET`/`HEAD /file={path_or_url:path}` returns `RedirectResponse(url=path_or_url, status_code=302)` whenever `is_http_url_like(path_or_url)` is true. Thus a launched stock Gradio app exposes `GET /gradio_api/file=https://attacker.example/` as a 302 whose `Location` is attacker-controlled. This is dependency code, but it executes as an endpoint of the launched application; code ownership does not make the active application advisory false. [PDFMathTranslate v1.9.9](https://github.com/PDFMathTranslate/PDFMathTranslate/releases/tag/v1.9.9) [v1.9.9 tree](https://github.com/PDFMathTranslate/PDFMathTranslate/tree/8ef72df455bd9cdae2666b8e63b8d298e5e5dd78) [Gradio 5.29.0 route](https://github.com/gradio-app/gradio/blob/479fc28f804c674e3705763be199dacb0f5dca79/gradio/routes.py#L906-L913)

## Atomic BIC and immediate parent

The atomic BIC is PR member `500bcca42f406dc8ac30c601208828af81fc12c1`, not PDFMathTranslate's integration commit and not Gradio's mainline squash. It adds exactly the vulnerable branch to the existing `/file={path:path}` handler:

```python
if utils.validate_url(path):
    return RedirectResponse(url=path, status_code=status.HTTP_302_FOUND)
```

Its single immediate parent is `b643ae77bfb465960af2f41f66351ef2a1b84d03`. The parent's same handler proceeds directly to local/encrypted-file checks and contains neither the URL predicate nor a redirect return, establishing immediate-parent absence. [BIC member](https://github.com/gradio-app/gradio/pull/2256/commits/500bcca42f406dc8ac30c601208828af81fc12c1) [BIC parent](https://github.com/gradio-app/gradio/commit/b643ae77bfb465960af2f41f66351ef2a1b84d03)

Later changes do not replace this first write: `431a987d612d5e43097898d13523fb72bdf84214` only renames `path` to `path_or_url`, `7ba8c5da45b004edd12c0460be9222f5b5f5f055` replaces `validate_url()` with `is_http_url_like()`, and the 5.0 route-prefix work moves the surviving handler beneath `/gradio_api`. Those are refactor/move or predicate changes, not the first writer of the vulnerable redirect sink. [rename commit](https://github.com/gradio-app/gradio/commit/431a987d612d5e43097898d13523fb72bdf84214) [predicate commit](https://github.com/gradio-app/gradio/commit/7ba8c5da45b004edd12c0460be9222f5b5f5f055) [5.29.0 route](https://github.com/gradio-app/gradio/blob/479fc28f804c674e3705763be199dacb0f5dca79/gradio/routes.py#L906-L913)

## Direct fix or unpatched state

The upstream direct fix is `1c5c53842df9c2750552d85c19a92e7e732cff3f`, parent `46d391bd4385b6cfa31f10b35955c95c86c4cb85`. It replaces the arbitrary 302 with `secure_url_stream_response()`, which validates/fetches and streams the external resource, and PR #13596 and the 6.20.0 release explicitly identify the old behavior as an open redirect. [direct fix](https://github.com/gradio-app/gradio/commit/1c5c53842df9c2750552d85c19a92e7e732cff3f) [PR #13596](https://github.com/gradio-app/gradio/pull/13596) [6.20.0 release](https://github.com/gradio-app/gradio/releases/tag/gradio%406.20.0)

There is no PDFMathTranslate direct-fix commit or fixed release in the inspected history. This is an unpatched consumer state with a fixed upstream dependency, not evidence that the vulnerability was fictitious.

## Corrections

- Replace primary verdict `FALSE_POSITIVE` with `NOT_AI`; an active dependency route exposed by the application is not disproved by the absence of first-party route code.
- Set `introducer_sha` to `500bcca42f406dc8ac30c601208828af81fc12c1`, `introducer_parent` to `b643ae77bfb465960af2f41f66351ef2a1b84d03`, and `introducer_parent_absent` to `true`.
- Set `squash_decomposed` to `true`; record the seven PR members above and treat `809230f25fc84e0109dd88cd5fe1c2874109bcad` only as their squash aggregate.
- Set `fix_sha` and `direct_fix_sha` to upstream `1c5c53842df9c2750552d85c19a92e7e732cff3f`; retain that no PDFMathTranslate fixed release exists.
- Replace the review's `EVIDENCE_GAP` AI marker with: `absent on atomic BIC; named human author/committer Abubakar Abid; no bot, generator, co-author, or AI marker on BIC`.

## Remaining gap

No causal or AI-attribution gap remains. A release-scope precision gap remains: because PDFMathTranslate 1.9.9 declared unpinned `gradio`, its installed Gradio version depends on resolution time, and the advisory does not explain why only PDFMathTranslate 1.9.9 is named. That does not block the demonstrated vulnerable configuration, atomic Gradio BIC, immediate-parent absence, direct fix, or `NOT_AI` verdict. A vendor/CNA correction could refine the affected-version range but is not required to close authorship.
