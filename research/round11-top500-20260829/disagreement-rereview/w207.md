## Vulnerability mechanism

CVE-2025-3931 is `PUBLISHED`, assigned by Red Hat, and describes missing authentication and authorization on Yggdrasil's D-Bus dispatch method: any system user could direct a package-management worker to install arbitrary RPMs, producing local privilege escalation. GitHub's reviewed GHSA is not withdrawn and records `<= 0.4.6`. [CVE record](https://cveawg.mitre.org/api/cve/CVE-2025-3931) [GHSA-rpg2-jvhp-h354](https://api.github.com/advisories/GHSA-rpg2-jvhp-h354)

The code mechanism is conjunctive. Commit `68ec1b65143352bc11dfd82bba5af56c6c2023c8` added `com.redhat.Yggdrasil1.Dispatch`, exported it on `/com/redhat/Yggdrasil1`, implemented `Dispatcher.Dispatch` without a `dbus.Sender` or authorization check, and added a `<policy context="default">` rule allowing any local user to send to `com.redhat.Yggdrasil1`. That method forwards attacker-controlled directive, message ID, metadata, and data into the worker dispatcher. [BIC commit](https://github.com/RedHatInsights/yggdrasil/commit/68ec1b65143352bc11dfd82bba5af56c6c2023c8)
