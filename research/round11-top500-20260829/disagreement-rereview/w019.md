# w019 re-research

## Decision

**AGREE** with the disagreement memo. Recommended primary verdict: `AI_ROOT_CAUSE`, but only for the session-token early-return constituent first written by `b47fa1c75d890cd080e3f6699bbfca8cd8d4b939`; it must not be read as AI attribution for every advisory-named sink. Recommended review verdict: `CORRECTION_REQUIRED`. The record must set `fix_sha` and `direct_fix_sha` to null and retain an explicit unpatched gap. The vendor advisory is published and not withdrawn, and CVE-2026-79665 is `PUBLISHED`, so `FALSE_POSITIVE` is not appropriate ([vendor advisory](https://github.com/lin-snow/Ech0/security/advisories/GHSA-hmmq-qh6g-6wgh), [CVE record](https://www.cve.org/CVERecord?id=CVE-2026-79665)).

## Vulnerability mechanism

The mechanism replay at the affected `v4.5.0` tag (`6e0f84f4880a3dc2900659846c4359add82ce5bf`) is:

1. Login JWT generation sets `typ=session`.
2. `RequireScopes` calls `ctx.Next()` immediately for `typ=session`, before scope or audience validation. Therefore any ordinary authenticated non-admin passes the only nominal admin guard on `/api/system/check-update`, `/api/system/logs`, `/api/system/logs/stream`, and `/api/system/visitor-stats`.
3. Those dashboard handlers and services contain no `IsAdmin` check. `GetAllUsers` likewise lacked a caller-role check and returned other users' records.
4. `/ws/system/logs` is registered on `WSRouterGroup`; that group has no authentication middleware, and `WSSubscribeSystemLogs` only parses the query JWT without checking admin role, scope, or audience.

These are the same three independent gaps stated by the [vendor advisory](https://github.com/lin-snow/Ech0/security/advisories/GHSA-hmmq-qh6g-6wgh). The replay is also visible directly in the repository objects for [`v4.5.0`](https://github.com/lin-snow/Ech0/tree/6e0f84f4880a3dc2900659846c4359add82ce5bf/internal): `internal/util/jwt/jwt.go`, `internal/middleware/scope.go`, `internal/router/router.go`, `internal/router/dashboard.go`, `internal/handler/dashboard/dashboard.go`, and `internal/service/user/user.go`.
