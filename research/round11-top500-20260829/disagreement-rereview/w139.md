# w139 re-research

## Decision

**DISAGREE** with the disagreement memo's current `EVIDENCE_GAP` conclusion. The memo correctly observes that the assigned `yoast-dist/duplicate-post` clone starts from a parentless release aggregate, but the case-authorized first-party source repository `Yoast/duplicate-post` contains both atomic introducers, their immediate parents, the unsquashed PR histories, the direct fix, and the release tags. Those objects close the attribution gates rather than merely repeating the primary report.

- Recommended primary verdict: `NOT_AI`.
- Recommended review verdict: `CORRECTION_REQUIRED`.
- Required primary correction: treat the advisory as two independently introduced vulnerable paths and retain both atomic BICs in the evidence, not only the older clone-path BIC.

## Vulnerability mechanism

The active CVE record is `PUBLISHED`, not rejected or withdrawn. The Wordfence CNA and GitHub reviewed advisory identify CWE-862 in versions through 4.5: `clone_bulk_action_handler()` permits a Contributor or higher to duplicate private, draft, or trashed posts, while `republish_request()` permits an Author or higher to overwrite another published post. Both identify 4.6 as patched ([CVE record](https://cveawg.mitre.org/api/cve/CVE-2026-1217), [GHSA-g9w4-m5fx-x3wv](https://github.com/advisories/GHSA-g9w4-m5fx-x3wv), [CNA advisory](https://www.wordfence.com/threat-intel/vulnerabilities/wordpress-plugins/duplicate-post/yoast-duplicate-post-45-authenticated-contributor-missing-authorization-to-arbitrary-post-duplication-and-overwrite)).

The mechanism replays directly at source tag 4.5, peeled to `be174d6c46f99f28ea0799c0ede43d32464d0612`:

- Bulk clone accepts the marked `$post_ids`, resolves each with `get_post()`, and reaches `duplicate_post_create_duplicate($post)` without `current_user_can('edit_post', $post_id)` ([4.5 bulk handler](https://github.com/Yoast/duplicate-post/blob/be174d6c46f99f28ea0799c0ede43d32464d0612/src/handlers/bulk-handler.php#L115-L136)).
- Rewrite & Republish resolves the original, calls `republish()`, rewrites the copy's ID to the original ID, and reaches `wp_update_post()` without checking `edit_post` on that original ([4.5 request](https://github.com/Yoast/duplicate-post/blob/be174d6c46f99f28ea0799c0ede43d32464d0612/src/post-republisher.php#L128-L149), [4.5 sink](https://github.com/Yoast/duplicate-post/blob/be174d6c46f99f28ea0799c0ede43d32464d0612/src/post-republisher.php#L304-L333)).

## Atomic BIC and immediate parent

That handler iterates caller-supplied post IDs and calls `duplicate_post_create_duplicate()` without a per-post capability check. Its sole immediate parent is `ced4ec4977c4bbb7c84c9b3f01671e107fe40a8b`; the file is absent from that parent. The commit is therefore the smallest surviving public first-write, not the later OOP move ([BIC](https://github.com/Yoast/duplicate-post/commit/8011c3bac314ce951abb9de13024626da1ae052b), [parent](https://github.com/Yoast/duplicate-post/commit/ced4ec4977c4bbb7c84c9b3f01671e107fe40a8b)).

Its hook reads `_dp_is_rewrite_republish_copy`, substitutes the original ID, and calls `wp_update_post()` without checking authorization for that original. Its sole immediate parent is `208cda0820731cc71d16d60865bc870a93bbdc10`; that parent has neither the new file nor the republish class, hook, or marker lookup. This is the smallest public first-write of the second path ([BIC](https://github.com/Yoast/duplicate-post/commit/cdf7678453a21548fda36a6b7105b1b475e2c145), [parent](https://github.com/Yoast/duplicate-post/commit/208cda0820731cc71d16d60865bc870a93bbdc10)).

The later `37503bcabe145c8c064b29b03b6949e2b3b9a6c5` OOP bulk-handler addition, `0cabd783643ae882e8dae2a63da7182d81ecabf2` republisher refactor, and `97b07853115e6153e829052b4e9fc42141a02da2` file renames preserve or move the already vulnerable logic; none is an atomic BIC ([bulk move](https://github.com/Yoast/duplicate-post/commit/37503bcabe145c8c064b29b03b6949e2b3b9a6c5), [republisher refactor](https://github.com/Yoast/duplicate-post/commit/0cabd783643ae882e8dae2a63da7182d81ecabf2), [renames](https://github.com/Yoast/duplicate-post/commit/97b07853115e6153e829052b4e9fc42141a02da2)).
