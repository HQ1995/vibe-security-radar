# w252 re-research

## Decision

**AGREE** with the disagreement memo. Recommended primary verdict: **`NOT_AI`**. Recommended review verdict: **`CONFIRMED`**, with a release-membership caveat rather than an authorship or causal evidence gap. ## Vulnerability mechanism

CVE-2026-6863 is a published CWE-863 cross-organization authorization bypass. The vendor and Rapid7 CNA record say that a root-organization reader holding only `READ_RESULTS` can issue one authenticated HTTP GET and read files from another organization; the reverse direction does not work ([vendor advisory](https://docs.velociraptor.app/announcements/advisories/cve-2026-6863/), [CVE Services record](https://cveawg.mitre.org/api/cve/CVE-2026-6863)).

The source-to-sink path is concrete in the affected tree. In the commit peeled from tag `v0.76.2`, `454a4df2995b27edad2b9af29e7942d126015e9a`, `vfsFileDownloadHandler`:

1. selects `org_config_obj` from the request's organization;
2. checks only `services.CheckAccess(org_config_obj, principal, acls.READ_RESULTS)`;
3. accepts attacker-controlled `FSComponents []string` with schema key `fs_components`;
4. turns those components directly into `path_specs.NewUnsafeFilestorePath(...).SetType(PATH_TYPE_FILESTORE_ANY)`; and
5. passes that path to `file_store.GetFileStore(org_config_obj).ReadFile(path_spec)` without `IsFileAccessible` ([affected `api/download.go`](https://github.com/Velocidex/velociraptor/blob/454a4df2995b27edad2b9af29e7942d126015e9a/api/download.go#L83-L193)).

The legacy `vfs_path` branch is not equivalent: `GetUploadsFileFromVFSPath` requires `clients/<requested-client>/collections/...` ([affected `paths/client.go`](https://github.com/Velocidex/velociraptor/blob/454a4df2995b27edad2b9af29e7942d126015e9a/paths/client.go#L108-L125)). Multi-tenant commit `61a51ac3c63edb78db6603aa4b2c6b01f8ae8dc7` places a child organization's datastore and filestore below the root configuration at `/orgs/<org_id>` ([organization layout](https://github.com/Velocidex/velociraptor/blob/61a51ac3c63edb78db6603aa4b2c6b01f8ae8dc7/services/orgs/orgs.go#L130-L141)). Thus a root-org filestore read of attacker-supplied `orgs/<other_org>/...` crosses the authorization boundary, while a sub-org filestore is already rooted below its own directory and cannot reach siblings or root. Commit `8df035da764c894da6cb878e04b493ed34c4eab3` had already wired organization IDs into the download handlers; it is necessary context, not the first write of the vulnerable arbitrary-path branch ([commit](https://github.com/Velocidex/velociraptor/commit/8df035da764c894da6cb878e04b493ed34c4eab3)).

## Atomic BIC and immediate parent

The atomic BIC is PR #2116 member **`83448b40d12d3349410d5c1edce3e09051bc7cd6`** ([commit](https://github.com/Velocidex/velociraptor/commit/83448b40d12d3349410d5c1edce3e09051bc7cd6), [PR #2116](https://github.com/Velocidex/velociraptor/pull/2116)). Its `api/download.go` diff first adds both `FSComponents []string` with schema tag `schema:"fs_components"` and the direct `NewUnsafeFilestorePath(request.FSComponents...)` branch.

Its sole immediate parent is **`d34aedc6ccd905e04ec0287a8cef5b09f07868ff`** ([parent](https://github.com/Velocidex/velociraptor/commit/d34aedc6ccd905e04ec0287a8cef5b09f07868ff)). Direct tree inspection of `d34aedc6ccd905e04ec0287a8cef5b09f07868ff:api/download.go` finds neither `FSComponents` nor `fs_components`. The parent's existing `NewUnsafeFilestorePath` call consumes internally derived download-info components, not attacker-controlled `FSComponents`. The vulnerable branch is therefore absent at the immediate parent and first present in `83448b40d12d3349410d5c1edce3e09051bc7cd6`.

The earlier multi-tenant and org-routing commits do not themselves write the vulnerable input-to-read path. Selecting them would confuse enabling context with the smallest commit that first wrote the vulnerable lines.

Both still contain the `FSComponents` unsafe-path branch and lack `IsFileAccessible` in `api/download.go` ([public v0.75 branch](https://github.com/Velocidex/velociraptor/tree/v0.75-release)).

`v0.76.2` is annotated tag object **`47363f87319b8ea9a80fdb68d73f67a35c4e1687`**, peeled commit **`454a4df2995b27edad2b9af29e7942d126015e9a`**. Backport **`7165598319110900ba077fecae2ff3391725be6b`** is an ancestor of the latter but not the former, and `v0.76.4:api/download.go` contains all four new `IsFileAccessible` calls ([v0.76.4 release](https://github.com/Velocidex/velociraptor/releases/tag/v0.76), [backport commit](https://github.com/Velocidex/velociraptor/commit/7165598319110900ba077fecae2ff3391725be6b)).

The vendor and CNA advertise “before 0.75.9” and “before 0.76.4” as affected and recommend 0.75.9 or 0.76.4 ([vendor advisory](https://docs.velociraptor.app/announcements/advisories/cve-2026-6863/), [CVE Services record](https://cveawg.mitre.org/api/cve/CVE-2026-6863)).
