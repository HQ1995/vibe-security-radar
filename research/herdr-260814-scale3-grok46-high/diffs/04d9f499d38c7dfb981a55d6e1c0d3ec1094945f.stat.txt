    Add --auto-files feature to extract modules and scripts from wheels
    
    Automatically populate %pyproject_save_files and %files sections by
    downloading the wheel and extracting module names from top_level.txt
    and console script names from entry_points.txt.
    
    - Add wheel_extractor module to download and parse wheel files
    - Extract top-level modules and console scripts from wheel dist-info
    - Add 'file_list' and 'scripts' fields to PackageInfo
    - Update spec template to include scripts in %files as %{_bindir}/name
    - Configure betamax to preserve exact body bytes for binary downloads
    - Use response.iter_content() to avoid gzip content-length mismatches
