    feat: add super admin role with instance-wide access
    
    This commit introduces a new super_admin role that allows designated users
    to manage the entire ShellHub instance across all namespaces.
    
    Backend changes:
    - Add super_admin boolean field to User model
    - Create migration 112 to add super_admin field to existing users
    - Update JWT claims to include super_admin status
    - Add /admin/users endpoint for super admin user management
    - Add OpenAPI validation middleware for response schema validation
    - Update auth service to handle super admin permissions
    - Add CLI support for promoting users to super admin
    
    Frontend changes:
    - Add SuperAdminToggle component in admin panel
    - Update user interfaces to include super_admin field
    - Add "Admin Console" button in namespace switcher for super admins
    - Update auth stores to track super admin status
    - Fix TypeScript errors in admin tests
    - Update gateway routing to support /admin/* paths
    
    The super admin role provides:
    - Access to /admin/ console for instance-wide management
    - Ability to view and manage all users across namespaces
    - Bypass namespace-level permissions for administrative tasks
