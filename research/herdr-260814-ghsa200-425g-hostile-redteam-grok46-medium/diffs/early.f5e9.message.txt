Implement MED-7/MED-8 security fixes: Secure JSON validation for CLI

This commit implements comprehensive security fixes for MED-7 (Insecure
File Metadata Parsing) and MED-8 (Insufficient JSON Validation)
vulnerabilities in the CLI components only.

Security improvements:
- Added JSON schema validation for all JSON file types
- Enhanced metadata parsing with size limits (512KB total, 64KB per value)
- DoS protection with max nesting depth (20 levels), object properties (1000)
- Comprehensive JSON structure validation for templates, keystores, and PQC keys
- Accommodates large PQC private keys while maintaining security boundaries

Files added:
- openssl_encrypt/schemas/*.json: JSON schema definitions
- openssl_encrypt/modules/json_validator.py: Secure JSON validation module

Files modified:
- crypt_utils.py: Enhanced parse_metadata with security limits and validation
- crypt_cli.py: Secure template loading and PQC key file validation
- crypt_core.py: Secure metadata parsing in decryption functions
- keystore_cli.py, pqc_keystore.py: Secure keystore file validation
- keystore_utils.py: Secure PQC key file loading
- crypt_settings.py: Secure configuration file validation

All changes include graceful fallbacks for environments without the
json_validator module to maintain backward compatibility.
