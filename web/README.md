# Catalog site

Next.js 16 static export of the public catalog. Data is generated by
`../scripts/publish_tp_ledger.py`, which reads Neon `ledger_rows`. The committed
jsonl file is a recovery export: `--from-export` restores offline, and
`--prefer-export` uses it only while its sha256 still matches the Neon snapshot
digest. Local `dev`/`build` use the committed generated JSON and never touch Neon;
`npm run research:data` is the explicit local Neon refresh. A push to `main`
builds and deploys that committed data; only a manual `Deploy Pages` dispatch
republishes from Neon, so CI stays off the metered free tier.

```bash
npm ci
npm run dev      # http://localhost:3000, no Neon
npm run build    # preflight + web/out/, no Neon
npm test         # vitest
```

| Route | Page |
|-------|------|
| `/` | Covered advisories, counts, disclosure trend |
| `/cves` | Findings list |
| `/cves/[id]` | Case detail |
| `/about` | How we verify |
| `/analytics`, `/tools` | Compatibility redirects |

Production: https://vibesecradar.com/. Pushes to `main` deploy via GitHub Actions.
